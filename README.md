# Process data Google Apps Script
Цель скрипта: автоматизация сборки и нормализации данных с листа "raw data" с сырыми данными от заказчика.

## Описание
По результатам работы скрипта данные по именам/фамилиям автоматически нормализуются.
Также обрабатываются даты (разбитие на составляющие) + проставляются стандартные/дефолтные значения, необходимые по формату таблиц (напр., interment_rights = Single).
Затем нормализованные данные проставляются на лист "Start" в необходимые столбцы.
После этого данные с листа "Start" разделяются на 3 таблицы: Site list, Deceased и Contacts.
